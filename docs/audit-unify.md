# Audit: what can become ONE shared piece (read-only, nothing built)

Scope: `OmniControl.App` (all `.axaml`, views, view-models, services). Method: grep of every `.axaml` for local Background/BorderBrush/CornerRadius/Padding/FontSize and class-less controls, then reading each repeat. Line numbers are as of this audit.

**Looks column.** `NO` = same pixels, safe to build without a visual. `YES` = something visibly changes (even slightly): needs the owner's visual approval first (AGENTS.md rule 1: show, approve, save mock-up to `docs/mockups/`, then build). `tiny` = a 1-8 px or wording difference between copies that would be unified; still needs a yes/no from the owner.

**Effort.** S = under an hour, one file or a style. M = a new control plus moving 3-10 users. L = touches many files or a model (view-model or catalogue).

**Ord** = suggested build order (1 = first). Shared pieces first, then the users that adopt them, then the look-changing ones once approved.

## What is already clean (checked, no finding)

- No `<Button>` anywhere has local Background/BorderBrush/CornerRadius/Padding/FontSize, and none lacks a master class.
- No colour literals in any `.axaml` (only `BrushDivider`, `BrushSidebar`, `BrushAccent` etc.).
- Every hotkey box is `HotkeyBox`; the capture pop-down and keycaps are the one `KeycapRow`/`HotkeyCapture`. Mouse and Picker path fields are `PathField`.
- Restore defaults is one shared piece (`RestoreBar`, `SettingsRestore`).
